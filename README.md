# 제2회 BDAI × 플랜잇 채용 연계 공모전 랜딩페이지

## 파일 구성
- `index.html` : 페이지 구조/콘텐츠
- `style.css` : 디자인/반응형
- `script.js` : 스크롤 등장 애니메이션
- `assets/hero-data-road.png` : 파란 데이터 도시 그래픽

## 로컬에서 확인
VS Code에서 폴더를 열고 `index.html`을 브라우저로 열면 기본 페이지가 보입니다.
권장: VS Code의 Live Server 확장 프로그램을 설치해 `index.html`을 실행하세요.

## GitHub Pages
1. GitHub에 새 Repository 생성
2. 이 폴더의 파일을 Repository에 업로드
3. Settings → Pages
4. Source를 `Deploy from a branch`로 선택
5. Branch를 `main` / `/(root)`로 선택 후 Save
6. 생성된 GitHub Pages 주소로 접속
